# Меры DAX для дашборда по представительствам

**Где создавать:** вкладка **Power Pivot → Меры → Создать меру…**
**Таблица для всех мер:** `ДП_Факт`.

В каждой мере заполните в окне:
- **Имя меры** — точно как в заголовке (без кавычек);
- **Формула** — текст из блока кода, **без** строки с именем;
- **Категория / формат** — как указано под формулой.

> **Имена таблиц — в одинарных кавычках:** `'ДП_Факт'[ВыручкаТг]`. Без кавычек Power Pivot не понимает кириллицу и пишет «недопустимый токен».
>
> **Разделитель аргументов.** В русском Excel в DAX обычно ставится `;` — так и написано ниже.
> Если после нажатия «Проверить формулу» Excel ругается на синтаксис, замените все `;` на `,`.
> Сложение условий `&&` и названия функций (`DIVIDE`, `CALCULATE` …) не меняются.

Создавайте меры **строго по порядку**: нижние ссылаются на верхние.

---

## 1. Базовые

**Выручка** — формат: Десятичное число, 0 знаков, разделитель групп разрядов
```
=SUM ( 'ДП_Факт'[ВыручкаТг] )
```

**Себестоимость** — Десятичное, 0 знаков
```
=SUM ( 'ДП_Факт'[СебестоимостьТг] )
```

**Валовая маржа** — Десятичное, 0 знаков
```
=[Выручка] - [Себестоимость]
```

**Маржа доля** — Процент, 1 знак
```
=DIVIDE ( [Валовая маржа]; [Выручка] )
```

**Месяцев в периоде** — Целое число
```
=COUNTROWS ( 'ДП_Календарь' )
```

**Дней в периоде** — Целое число
```
=SUM ( 'ДП_Календарь'[Дней] )
```

**Средние запасы** — Десятичное, 0 знаков
*(средний остаток на конец месяца за выбранные месяцы; месяц без остатка считается нулём)*
```
=DIVIDE ( SUM ( 'ДП_Факт'[ЗапасыТг] ); [Месяцев в периоде] )
```

**Запасы на конец** — Десятичное, 0 знаков
*(остаток на последний месяц выбранного периода)*
```
=VAR d = MAX ( 'ДП_Календарь'[Дата] )
RETURN CALCULATE ( SUM ( 'ДП_Факт'[ЗапасыТг] ); 'ДП_Календарь'[Дата] = d )
```

**DIO** — Десятичное, 1 знак
*(за один месяц совпадает с DIO на листе «Расчет»; за период — агрегированная оборачиваемость, а не среднее из месячных DIO)*
```
=VAR c = [Себестоимость]
RETURN IF ( c > 0; DIVIDE ( [Средние запасы] * [Дней в периоде]; c ) )
```

**Оборачиваемость** — Десятичное, 1 знак (раз в год)
```
=DIVIDE ( 365; [DIO] )
```

## 2. Доли и перекос (относительно всей компании за тот же период)

**Выручка компании** — Десятичное, 0 знаков
```
=CALCULATE ( [Выручка]; ALL ( 'ДП_Представительства' ); ALL ( 'ДП_Факт'[Представительство] ) )
```

**Доля выручки** — Процент, 1 знак
```
=DIVIDE ( [Выручка]; [Выручка компании] )
```

**Средние запасы компании** — Десятичное, 0 знаков
```
=CALCULATE ( [Средние запасы]; ALL ( 'ДП_Представительства' ); ALL ( 'ДП_Факт'[Представительство] ) )
```

**Доля запасов** — Процент, 1 знак
```
=DIVIDE ( [Средние запасы]; [Средние запасы компании] )
```

**Перекос** — Процент, 1 знак
*(плюс = на складе лежит непропорционально много по сравнению с продажами)*
```
=[Доля запасов] - [Доля выручки]
```

## 3. Излишек запасов («замороженные деньги» сверх цели по DIO)

**Цель DIO** — Целое число
```
=MAX ( 'ДП_Параметры'[Цель_DIO] )
```

**Норматив запасов** — Десятичное, 0 знаков
*(сколько запасов было бы при целевом DIO)*
```
=DIVIDE ( [Себестоимость]; [Дней в периоде] ) * [Цель DIO]
```

**Излишек запасов** — Десятичное, 0 знаков
*(считается по каждому представительству отдельно и складывается — излишек одного не «гасится» недостатком другого; запасы без продаж целиком считаются излишком)*
```
=SUMX (
    VALUES ( 'ДП_Представительства'[Представительство] );
    VAR s = [Средние запасы]
    VAR n = [Норматив запасов]
    VAR n0 = IF ( n > 0; n; 0 )
    RETURN IF ( s > n0; s - n0; 0 )
)
```

## 4. Сравнение с предыдущим периодом и с прошлым годом

«Предыдущий период» = столько же месяцев сразу перед выбранными (выбрали 3 мес. → сравнение с 3 предыдущими).
Если сравнивать не с чем (периода нет в истории), мера пустая — это правильно.

**Выручка пред период** — Десятичное, 0 знаков
```
=VAR mn = MIN ( 'ДП_Календарь'[МесяцИндекс] )
VAR n = MAX ( 'ДП_Календарь'[МесяцИндекс] ) - mn + 1
VAR perv = CALCULATE ( MIN ( 'ДП_Календарь'[МесяцИндекс] ); ALL ( 'ДП_Календарь' ) )
RETURN IF ( mn - n >= perv;
    CALCULATE ( [Выручка];
        FILTER ( ALL ( 'ДП_Календарь' );
            'ДП_Календарь'[МесяцИндекс] >= mn - n && 'ДП_Календарь'[МесяцИндекс] <= mn - 1 ) ) )
```

**Прирост выручки** — Процент, 1 знак
```
=VAR b = [Выручка пред период]
RETURN IF ( b > 0; DIVIDE ( [Выручка] - b; b ) )
```

**DIO пред период** — Десятичное, 1 знак
```
=VAR mn = MIN ( 'ДП_Календарь'[МесяцИндекс] )
VAR n = MAX ( 'ДП_Календарь'[МесяцИндекс] ) - mn + 1
VAR perv = CALCULATE ( MIN ( 'ДП_Календарь'[МесяцИндекс] ); ALL ( 'ДП_Календарь' ) )
RETURN IF ( mn - n >= perv;
    CALCULATE ( [DIO];
        FILTER ( ALL ( 'ДП_Календарь' );
            'ДП_Календарь'[МесяцИндекс] >= mn - n && 'ДП_Календарь'[МесяцИндекс] <= mn - 1 ) ) )
```

**Дельта DIO** — Десятичное, 1 знак
```
=VAR a = [DIO]
VAR b = [DIO пред период]
RETURN IF ( NOT ISBLANK ( a ) && NOT ISBLANK ( b ); a - b )
```

**Выручка год назад** — Десятичное, 0 знаков
```
=VAR mn = MIN ( 'ДП_Календарь'[МесяцИндекс] )
VAR mx = MAX ( 'ДП_Календарь'[МесяцИндекс] )
VAR perv = CALCULATE ( MIN ( 'ДП_Календарь'[МесяцИндекс] ); ALL ( 'ДП_Календарь' ) )
RETURN IF ( mn - 12 >= perv;
    CALCULATE ( [Выручка];
        FILTER ( ALL ( 'ДП_Календарь' );
            'ДП_Календарь'[МесяцИндекс] >= mn - 12 && 'ДП_Календарь'[МесяцИндекс] <= mx - 12 ) ) )
```

**Прирост выручки гг** — Процент, 1 знак
```
=VAR b = [Выручка год назад]
RETURN IF ( b > 0; DIVIDE ( [Выручка] - b; b ) )
```

**DIO год назад** — Десятичное, 1 знак
```
=VAR mn = MIN ( 'ДП_Календарь'[МесяцИндекс] )
VAR mx = MAX ( 'ДП_Календарь'[МесяцИндекс] )
VAR perv = CALCULATE ( MIN ( 'ДП_Календарь'[МесяцИндекс] ); ALL ( 'ДП_Календарь' ) )
RETURN IF ( mn - 12 >= perv;
    CALCULATE ( [DIO];
        FILTER ( ALL ( 'ДП_Календарь' );
            'ДП_Календарь'[МесяцИндекс] >= mn - 12 && 'ДП_Календарь'[МесяцИндекс] <= mx - 12 ) ) )
```

**Дельта DIO гг** — Десятичное, 1 знак
```
=VAR a = [DIO]
VAR b = [DIO год назад]
RETURN IF ( NOT ISBLANK ( a ) && NOT ISBLANK ( b ); a - b )
```

**Дельта DIO значимая** — Десятичное, 1 знак
*(та же Дельта DIO, но только для представительств с долей выручки не ниже порога — убирает шум от мелких)*
```
=IF ( [Доля выручки] >= MAX ( 'ДП_Параметры'[Порог_доли] ); [Дельта DIO] )
```

## 5. Служебные

**Период текст** — формат не задаётся (текст)
```
=FORMAT ( MIN ( 'ДП_Календарь'[Дата] ); "MM.yyyy" ) & " – "
    & FORMAT ( MAX ( 'ДП_Календарь'[Дата] ); "MM.yyyy" ) & "  ·  "
    & [Месяцев в периоде] & " мес."
```

**Активных представительств** — Целое число
```
=COUNTROWS ( FILTER ( VALUES ( 'ДП_Представительства'[Представительство] ); [Выручка] > 0 ) )
```

**Ранг по выручке** — Целое число
```
=IF ( HASONEVALUE ( 'ДП_Представительства'[Представительство] ) && NOT ISBLANK ( [Выручка] );
    RANKX ( ALLSELECTED ( 'ДП_Представительства'[Представительство] ); [Выручка] ) )
```

## 6. Те же суммы в миллионах (для таблиц, графиков и карточек)

Все — Десятичное число, **1 знак**, с разделителем разрядов.

**Выручка млн**
```
=DIVIDE ( [Выручка]; 1000000 )
```

**Валовая маржа млн**
```
=DIVIDE ( [Валовая маржа]; 1000000 )
```

**Средние запасы млн**
```
=DIVIDE ( [Средние запасы]; 1000000 )
```

**Запасы на конец млн**
```
=DIVIDE ( [Запасы на конец]; 1000000 )
```

**Излишек запасов млн**
```
=DIVIDE ( [Излишек запасов]; 1000000 )
```
