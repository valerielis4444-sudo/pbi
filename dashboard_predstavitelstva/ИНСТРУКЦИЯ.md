# Новый дашборд по представительствам — пошаговая инструкция

Работаем **только** с блоком представительств. Общий дашборд, «Данные», «Расчет» и остальные листы не трогаем.

---

## Что получится в итоге

**Лист «Дашборд_представительства»** (для директора):
- **Временная шкала** сверху: выбор периода мышкой (месяц, квартал, год, любой диапазон).
- **Срезы** слева:
  - **Статус**: «Продаёт» / «Запасы без продаж 3 мес.» / «Неактивно»;
  - **Класс ABC**: A — первые 80% выручки, B — следующие 15%, C — хвост;
  - **Представительство**: можно выбрать одно или несколько через Ctrl.
- **6 карточек KPI**: выручка (+ прирост к прошлому году), маржа %, средние запасы, DIO (+ изменение к предыдущему периоду), излишек запасов сверх цели, число активных представительств.
- **4 графика:**
  - «Выручка и DIO по месяцам» — за всю историю, по выбранным представительствам;
  - «Топ-15: где заморожено больше всего денег (излишек запасов)»;
  - «Топ-15 по перекосу: доля в запасах выше доли в выручке»;
  - «Структура выручки по классам ABC».
- **Рейтинг** (топ-25 по выручке за выбранный период): ранг, выручка, доля, прирост, маржа, средние запасы, DIO, изменение DIO, доля в запасах, перекос, излишек. Всё с цветовой подсветкой.

**Лист «Карта_DIO»**:
- «Топ-10 представительств, где DIO ухудшился сильнее всего».
- Тепловая карта «представительство × месяц» по DIO.

**Все элементы реагируют на все фильтры.** Исключение — график динамики: он не подчиняется временной шкале, чтобы всегда показывать тренд. Новые месяцы появляются сами по кнопке **Данные → Обновить всё**.

## Что исправлено по сравнению со старым блоком

| Было | Стало |
|---|---|
| Новые месяцы теряли продажи и запасы «без представительства» (август: −6,7 млн выручки, −80,6 млн запасов) | Эти суммы сохраняются. Итог по представительствам = итог компании |
| Если в папку попадёт второй файл остатков за тот же месяц, запасы удвоятся | Один месяц = один файл (самый свежий) |
| DIO новых месяцев всегда считался по средним остаткам и без товара в пути | Одна методика для всей истории: как на листе «Расчет» при «На конец периода» и «Товар в пути = Да» |
| Сравнение с прошлым месяцем ломалось на месяцах в 30 и 31 день (`EDATE`) | Сравнение по номеру месяца, ошибки нет |
| При выборе периода доли и перекос брались за весь период | Все показатели считаются за выбранный период |
| Выбор только из трёх вариантов периода, представительства не выбрать | Любой период на шкале и любые представительства в срезах |
| «Отсортировано по выручке» — на деле по алфавиту | Сортировка и топ-N — настоящие |
| Проверки корректности не было | Лист «ДП_Сверка»: после каждого обновления сравнивает итоги с общей моделью |

## Шаг 0. Подготовка (5 минут)

1. **Сделайте копию файла** и работайте в копии. Старый блок удалим только в самом конце, когда новый пройдёт все проверки.
2. **Проверьте версию Excel:** **Файл → Учётная запись → «О программе Excel»**. В первой строке будет, например, «Microsoft® Excel® для Microsoft 365 MSO (версия 2408…)» или «Excel 2016/2019/2021».
   - Нужен **Excel 2016 или новее для Windows**. На Mac Power Pivot нет, и этот вариант не подойдёт.
3. **Включите Power Pivot:** **Файл → Параметры → Надстройки → внизу «Управление: Надстройки COM» → Перейти → галочка «Microsoft Power Pivot for Excel» → ОК**.
   - Должна появиться вкладка **Power Pivot**.
   - **Если такой надстройки в списке нет, остановитесь и напишите мне.** Я дам вариант без Power Pivot.

> **Пришлите мне строку из «О программе» и сообщите, появилась ли вкладка Power Pivot.**

## Шаг 2. Технический лист и таблица параметров

1. Создайте новый лист **`ДП_Своды`**. Здесь будут служебные сводные таблицы; в конце лист скроем.
2. На нём в ячейки **R3:S4** введите:

   | R3: `Цель_DIO` | S3: `Порог_доли` |
   |---|---|
   | R4: `=Параметры!C23` | S4: `0,001` |

3. Выделите R3:S4 → **Вставка → Таблица** → галочка «Таблица с заголовками» → ОК.
4. **Конструктор таблиц → Имя таблицы:** `tblДП_Параметры`.

`Параметры!C23` — это цель DIO со светофора (45 дней). Изменили цель на листе «Параметры» → нажали «Обновить всё» → излишек пересчитается.

## Шаг 3. Запросы Power Query (8 штук)

Код каждого запроса — в папке `power_query/`. Файлы нумерованы, **создавайте строго по порядку**.

**Как создать один запрос:**
1. **Данные → Получить данные → Из других источников → Пустой запрос.**
2. В редакторе: **Главная → Расширенный редактор** → удалите всё → вставьте содержимое файла **целиком**. Строки с `//` — комментарии, их можно оставить → **Готово**.
3. Справа в «Параметры запроса → Свойства → Имя» впишите имя из первой строки файла, например `ДП_История`.
4. Создайте следующий запрос (снова «Новый источник → Другие источники → Пустой запрос» прямо в редакторе) и так далее.

| № | Файл | Имя запроса |
|---|---|---|
| 1 | `01_ДП_История.m` | `ДП_История` |
| 2 | `02_fnДП_Остатки.m` | `fnДП_Остатки` |
| 3 | `03_ДП_Продажи.m` | `ДП_Продажи` |
| 4 | `04_ДП_Факт.m` | `ДП_Факт` |
| 5 | `05_ДП_Календарь.m` | `ДП_Календарь` |
| 6 | `06_ДП_Представительства.m` | `ДП_Представительства` |
| 7 | `07_ДП_Параметры.m` | `ДП_Параметры` |
| 8 | `08_ДП_Сверка.m` | `ДП_Сверка` |

**Путь к папке «Запасы»** прописан в `02_fnДП_Остатки.m` таким же, как в ваших рабочих запросах: `C:\Users\v.lis\Desktop\ФинЦикл\Расчёт и анализ ФЦ\Запасы`. Если на другом компьютере он другой, поменяйте только эту строку.

**Как загрузить.** Главная → **Закрыть и загрузить → Закрыть и загрузить в…**. Настройка разная для каждого запроса:

| Запрос | «Только создать подключение» | «Добавить эти данные в модель данных» |
|---|---|---|
| ДП_История, fnДП_Остатки, ДП_Продажи | ✔ | — |
| ДП_Факт, ДП_Календарь, ДП_Представительства, ДП_Параметры | ✔ | ✔ |
| ДП_Сверка | — («Таблица», **Новый лист**) | — |

Уже созданный запрос можно перенастроить: панель «Запросы и подключения» → правый клик по запросу → **Загрузить в…**

Лист со сверкой переименуйте в **`ДП_Сверка`**.

> Первое обновление может занять несколько минут: запросы читают OLAP-куб и все файлы из папки.
> Если какой-то запрос выдаёт ошибку, **пришлите мне точный текст ошибки и имя запроса**.

## Шаг 4. Проверка данных — самый важный шаг

Откройте лист **ДП_Сверка**. В столбце **Статус** везде должно быть **OK**.

Если где-то «РАСХОЖДЕНИЕ», посмотрите, в каком столбце Δ ненулевое значение, и пришлите мне скриншот. Возможные причины:
- **Δ_Выручка** — в кубе у продаж без представительства есть имя-заглушка. Выручку это не теряет, так что такого быть не должно.
- **Δ_Склад ровно в 2 раза** — в папке два набора файлов за месяц. Дашборд здесь прав, а лист «Данные» считает дважды: это ошибка общей модели, о ней я писал раньше.
- **Δ_Склад на небольшую сумму** — в файлах есть строки с другой датой или «Итого».

Затем быстрая проверка в любой пустой ячейке:
- `=СУММ(ДП_Сверка[Выручка_дашборд])` — выручка за всю историю.
- Строка за **31.08.2026** должна дать:
  - Выручка_дашборд = **1 802 997 920,26**;
  - Себест_дашборд = **1 275 643 252,50**;
  - Склад_дашборд = **3 181 528 691,44**;
  - Путь_дашборд = **59 852 883,08**.

  Это в точности строка 38 листа «Данные».

> **Пришлите мне результат шага 4, прежде чем идти дальше.** Если сверка не сходится, строить дашборд бессмысленно.

## Шаг 7. Служебные сводные на листе ДП_Своды

Каждая сводная: **Вставка → Сводная таблица → «Из модели данных»** → «Существующий лист» → ячейка из таблицы ниже.

**Сразу после создания** каждой сводной: правый клик → **Параметры сводной таблицы**:
- «Имя» — как в таблице ниже;
- **снять** галочку «Автоматически изменять ширину столбцов при обновлении»;
- **поставить** «Сохранять форматирование ячеек при обновлении»;
- «Для пустых ячеек отображать»: `–`.

Поля «Представительство», «Класс ABC», «Статус» **всегда берите из таблицы ДП_Представительства**, а не из ДП_Факт.

| Имя сводной | Ячейка | Строки | Значения | Дополнительно |
|---|---|---|---|---|
| **П_KPI** | A3 | — | Период текст, Выручка млн, Прирост выручки гг, Маржа доля, Средние запасы млн, DIO, Дельта DIO, Излишек запасов млн, Активных представительств, Цель DIO | Только значения, без строк |
| **П_Динамика** | A10 | ДП_Календарь → Месяц | Выручка млн, DIO | — |
| **П_Излишек** | E10 | ДП_Представительства → Представительство | Излишек запасов млн | Фильтр по значению → Первые 10 → **15** элементов по «Излишек запасов млн»; сортировка по убыванию этой меры |
| **П_Перекос** | I10 | ДП_Представительства → Представительство | Перекос | Первые **15** по «Перекос»; сортировка по убыванию |
| **П_ABC** | M10 | ДП_Представительства → Класс ABC | Выручка млн | — |

Как ставить фильтр «Первые N»: стрелка у заголовка «Названия строк» → **Фильтры по значению → Первые 10…** → число → «элементов» → нужная мера.

## Шаг 8. Лист дашборда

1. Старый лист `Дашборд_представительства` переименуйте в **`Дашборд_предст_СТАРЫЙ`**. Не удаляйте его до шага 12.
2. Создайте новый лист **`Дашборд_представительства`**.
3. **Вид:** снимите «Сетка» и «Заголовки». **Масштаб:** 80–90%.
4. **Ширина столбцов:** A = 2, B:D = 13, E = 2, F = 30 (здесь названия представительств в рейтинге), G:Q = 11.

### 8.1 Заголовок и сверка
- **B2:** `ПРЕДСТАВИТЕЛЬСТВА — ПРОДАЖИ, ЗАПАСЫ И ОБОРАЧИВАЕМОСТЬ` (шрифт 20, полужирный, тёмно-синий `#1F3864`).
- **B3:** период из сводной. Поставьте `=`, перейдите на лист ДП_Своды и кликните по ячейке со значением «Период текст» в П_KPI. Excel сам построит формулу `ПОЛУЧИТЬ.ДАННЫЕ.СВОДНОЙ.ТАБЛИЦЫ(...)`. Оберните её: `="Период: "&ЕСЛИОШИБКА( <эта формула> ;"—")`.
  - Если вместо этой формулы получилась простая ссылка вида `=ДП_Своды!A4`, включите опцию: **Анализ сводной таблицы → Параметры (стрелка) → Создать GetPivotData** и повторите.
- **M3:**
  ```
  =ЕСЛИ(СЧЁТЕСЛИ(ДП_Сверка[Статус];"РАСХОЖДЕНИЕ")=0;"✔ Данные сверены с общей моделью";"⚠ Есть расхождения — см. лист ДП_Сверка")
  ```
  Добавьте условное форматирование: если текст содержит «⚠» — красный шрифт, иначе зелёный.

**Разметка листа сверху вниз:** строки 2–3 — заголовок; 5–8 — временная шкала; 10–13 — карточки KPI; 15–48 — графики; с 50 — рейтинг. Левая колонка B:D с 5-й строки — срезы.

### 8.2 Карточки KPI (строки 10–13)
Шесть карточек по две колонки: **F:G, H:I, J:K, L:M, N:O, P:Q**. В каждой карточке:
- **строка 10** — подпись (серый шрифт, 9 pt);
- **строки 11–12** — значение: объединить, шрифт 22, полужирный;
- **строка 13** — пояснение или изменение (9 pt).

Значения берутся из П_KPI: `=` → клик по нужному числу в П_KPI. Каждую формулу оберните в `ЕСЛИОШИБКА(…;"–")`.

| Карточка | Строка 10 | Строки 11–12 | Строка 13 | Формат значения |
|---|---|---|---|---|
| 1 | Выручка, млн ₸ | Выручка млн | Прирост выручки гг, подпись «к прошлому году» | `# ##0,0` / `+0,0%;-0,0%` |
| 2 | Валовая маржа | Маржа доля | — | `0,0%` |
| 3 | Средние запасы, млн ₸ | Средние запасы млн | — | `# ##0,0` |
| 4 | DIO, дней | DIO | Дельта DIO, подпись «к пред. периоду» | `0,0` / `+0,0;-0,0` |
| 5 | Излишек запасов, млн ₸ | Излишек запасов млн | `="сверх цели DIO "&<Цель DIO>&" дн."` | `# ##0,0` |
| 6 | Активных представительств | Активных представительств | — | `0` |

**Цвет изменений** (условное форматирование строки 13):
- **прирост выручки:** > 0 — зелёный `#2E7D32`, < 0 — красный `#C62828`;
- **Дельта DIO:** наоборот, > 0 красный (запасы оборачиваются медленнее), < 0 зелёный.

**Оформление карточки:** заливка `#F2F4F8`, тонкая рамка `#D0D7E2`.

### 8.3 Временная шкала и срезы
Кликните по любой ячейке сводной П_KPI (лист ДП_Своды):
- **Анализ сводной таблицы → Вставить временную шкалу** → ДП_Календарь → Дата.
  - Вырежьте её (Ctrl+X), вставьте на дашборд и растяните по области **F5:Q8**. Уровень — «Месяцы».
- **Анализ сводной таблицы → Вставить срез** → ДП_Представительства → Статус, Класс ABC, Представительство.
  - Перенесите в левую колонку B:D с 5-й строки: Статус сверху, Класс ABC ниже, Представительство — длинный срез до строки ~48.
  - Для среза «Представительство»: правый клик → **Настройка среза** → галочка **«Скрыть элементы без данных»**. Тогда при выборе класса ABC или статуса список сам сузится.

**Подключите фильтры ко всем сводным.** Правый клик по фильтру → **Подключения к отчётам**:

| Фильтр | Подключить к |
|---|---|
| Временная шкала | П_KPI, П_Излишек, П_Перекос, П_ABC, П_Рейтинг, П_ТопDIO, П_Карта. **Не** П_Динамика |
| Срез «Статус» | Все 8 сводных |
| Срез «Представительство» | Все 8 сводных |
| Срез «Класс ABC» | Все, кроме П_ABC: график структуры по ABC при выборе одного класса теряет смысл |

П_Рейтинг, П_ТопDIO и П_Карта появятся на шагах 8.5 и 9. Вернитесь к подключениям, когда их создадите.

### 8.4 Графики
Кликните в служебную сводную → **Анализ сводной таблицы → Сводная диаграмма** → **Конструктор → Переместить диаграмму → На имеющемся листе: Дашборд_представительства**. На каждом графике: **Анализ → Кнопки полей → Скрыть все**.

| График | Из сводной | Тип | Где разместить | Настройка |
|---|---|---|---|---|
| **Выручка и DIO по месяцам (вся история)** | П_Динамика | Комбинированная: «Выручка млн» — гистограмма, «DIO» — линия на **вспомогательной оси** | F15:K31 | Заголовок: «Выручка (млн ₸) и DIO (дней) по месяцам — выбранные представительства, вся история» |
| **Топ-15: излишек запасов** | П_Излишек | Линейчатая | L15:Q31 | Ось категорий: «Обратный порядок категорий», чтобы крупнейший был сверху. Подписи данных `# ##0` |
| **Топ-15: перекос запасы vs выручка** | П_Перекос | Линейчатая | F32:K48 | Обратный порядок; подписи `+0,0%` |
| **Структура выручки по ABC** | П_ABC | Кольцевая | L32:Q48 | Подписи: доля (%) + имя категории |

**Цвета** (одна палитра на всё): основной `#1F3864`, акцент `#2E75B6`, линия DIO `#ED7D31`, «плохо» `#C62828`. Шрифт графиков — как на листе, 9–10 pt. Легенды снизу.

### 8.5 Рейтинг представительств (внизу листа)
- **F50:** заголовок `РЕЙТИНГ ПРЕДСТАВИТЕЛЬСТВ — ТОП-25 ПО ВЫРУЧКЕ ЗА ВЫБРАННЫЙ ПЕРИОД`.
- **F51:** сводная из модели данных, имя **П_Рейтинг**.
  - **Строки:** ДП_Представительства → Представительство.
  - **Значения по порядку** (в скобках — новая подпись столбца: правый клик → «Параметры поля значений» → «Пользовательское имя»):

    | Мера | Подпись |
    |---|---|
    | Ранг по выручке | № |
    | Выручка млн | Выручка, млн ₸ |
    | Доля выручки | Доля в выручке |
    | Прирост выручки | Прирост к пред. периоду |
    | Маржа доля | Маржа |
    | Средние запасы млн | Ср. запасы, млн ₸ |
    | DIO | DIO, дн. |
    | Дельта DIO | Δ DIO |
    | Доля запасов | Доля в запасах |
    | Перекос | Перекос |
    | Излишек запасов млн | Излишек, млн ₸ |

  - **Фильтр:** Первые 10 → **25** элементов по «Выручка млн».
  - **Сортировка:** по убыванию «Выручка млн».
  - **Макет:** «Конструктор → Макет отчёта → Показать в табличной форме». Общие итоги — только по столбцам (строка «Итого» = показатели всей выборки).
- **Условное форматирование.** В каждом правиле в окне «Применить правило к» выберите вариант **«Все ячейки, содержащие значения "…" для "Представительство"»** — тогда формат переживёт обновление и смену фильтров.

  | Столбец | Правило |
  |---|---|
  | Выручка | Гистограммы (синие, сплошная заливка) |
  | DIO | Цветовая шкала: зелёный (меньше) → жёлтый → красный (больше) |
  | Δ DIO | Значки «стрелки»: вверх — красная (стало хуже), вниз — зелёная |
  | Перекос | > 0 — светло-красная заливка |
  | Излишек | Гистограммы (красные) |

- Хотите показать не 25, а 50: стрелка у «Названия строк» → Фильтры по значению → поменять число. Ниже рейтинга на листе ничего нет, поэтому таблица может расти вниз без ошибок.

## Шаг 9. Лист «Карта_DIO»

1. Новый лист **`Карта_DIO`**, сетку скрыть.
2. **Топ-10 ухудшения.** B4 — сводная **П_ТопDIO**:
   - строки: Представительство;
   - значения: DIO пред период («DIO было»), DIO («DIO стало»), Дельта DIO значимая («Рост DIO, дн.»);
   - фильтр «Первые 10» по «Дельта DIO значимая», сортировка по убыванию.

   Представительства с долей выручки меньше 0,1% сюда не попадают (порог — в tblДП_Параметры), чтобы не ловить шум от мелких.
3. **Тепловая карта.** B20 — сводная **П_Карта**:
   - строки: Представительство;
   - столбцы: ДП_Календарь → Месяц;
   - значения: DIO;
   - общие итоги по строкам: вкл. — это DIO за весь выбранный период;
   - условное форматирование на значения DIO: цветовая шкала зелёный → жёлтый → красный, «Все ячейки, содержащие значения DIO для Представительство и Месяц».

   Шкала подчиняется временной шкале, поэтому на карте видны только выбранные месяцы.
4. **Фильтры на этом листе.** Выделите на дашборде временную шкалу и три среза → Ctrl+C → на «Карта_DIO» → Ctrl+V. Скопированные фильтры **синхронизированы** с дашбордом: это те же самые фильтры. Разместите их над таблицами.
5. Подключите П_ТопDIO и П_Карта ко всем фильтрам (см. таблицу в шаге 8.3).

## Ежемесячное обновление

1. Положить в папку «Запасы» файл остатков за новый месяц (и «Товар в пути», если есть).
2. Дождаться закрытия месяца в кубе GEFEST.
3. **Данные → Обновить всё.**
4. Посмотреть индикатор на дашборде: должен быть «✔ Данные сверены».

Новый месяц появится в шкале, графиках, рейтинге и карте сам. Классы ABC и статусы пересчитаются по последним 12 и 3 месяцам.
