# Меры DAX для дашборда ПБЕ (создаются макросом автоматически)

Таблица мер: `ДПБ_Факт`. Формат: D0/D1 — десятичное 0/1 знак, P1 — процент, W — целое, G — общий.

**Оборот Дт** — D0
```
SUM('ДПБ_Факт'[ОборотДтТг])
```

**Оборот Кт** — D0
```
SUM('ДПБ_Факт'[ОборотКтТг])
```

**Месяцев ПБЕ** — W
```
COUNTROWS('ДПБ_Календарь')
```

**Дней ПБЕ** — W
```
SUM('ДПБ_Календарь'[Дней])
```

**Средняя ДЗ** — D0
```
DIVIDE(SUM('ДПБ_Факт'[ДЗТг]);[Месяцев ПБЕ])
```

**ДЗ на конец** — D0
```
VAR d = MAX('ДПБ_Календарь'[Дата]) RETURN CALCULATE(SUM('ДПБ_Факт'[ДЗТг]);'ДПБ_Календарь'[Дата] = d)
```

**Авансы на конец** — D0
```
VAR d = MAX('ДПБ_Календарь'[Дата]) RETURN CALCULATE(SUM('ДПБ_Факт'[АвансыТг]);'ДПБ_Календарь'[Дата] = d)
```

**DSO** — D1
```
VAR t = [Оборот Дт] RETURN IF(t > 0;DIVIDE([Средняя ДЗ] * [Дней ПБЕ];t))
```

**Инкассация** — P1
```
DIVIDE([Оборот Кт];[Оборот Дт])
```

**Оборот Дт компании** — D0
```
CALCULATE([Оборот Дт];ALL('ДПБ_ПБЕ');ALL('ДПБ_Факт'[ПБЕ]))
```

**Доля оборота** — P1
```
DIVIDE([Оборот Дт];[Оборот Дт компании])
```

**Средняя ДЗ компании** — D0
```
CALCULATE([Средняя ДЗ];ALL('ДПБ_ПБЕ');ALL('ДПБ_Факт'[ПБЕ]))
```

**Доля ДЗ** — P1
```
DIVIDE([Средняя ДЗ];[Средняя ДЗ компании])
```

**Перекос ДЗ** — P1
```
[Доля ДЗ] - [Доля оборота]
```

**Цель DSO** — W
```
MAX('ДПБ_Параметры'[Цель_DSO])
```

**Норматив ДЗ** — D0
```
DIVIDE([Оборот Дт];[Дней ПБЕ]) * [Цель DSO]
```

**Излишек ДЗ** — D0
```
SUMX(VALUES('ДПБ_ПБЕ'[ПБЕ]);VAR s = [Средняя ДЗ] VAR n = [Норматив ДЗ] VAR n0 = IF(n > 0;n;0) RETURN IF(s > n0;s - n0;0))
```

**Оборот Дт пред период** — D0
```
VAR mn = MIN('ДПБ_Календарь'[МесяцИндекс]) VAR n = MAX('ДПБ_Календарь'[МесяцИндекс]) - mn + 1 VAR perv = CALCULATE(MIN('ДПБ_Календарь'[МесяцИндекс]);ALL('ДПБ_Календарь')) RETURN IF(mn - n >= perv;CALCULATE([Оборот Дт];FILTER(ALL('ДПБ_Календарь');'ДПБ_Календарь'[МесяцИндекс] >= mn - n && 'ДПБ_Календарь'[МесяцИндекс] <= mn - 1)))
```

**Прирост оборота** — P1
```
VAR b = [Оборот Дт пред период] RETURN IF(b > 0;DIVIDE([Оборот Дт] - b;b))
```

**DSO пред период** — D1
```
VAR mn = MIN('ДПБ_Календарь'[МесяцИндекс]) VAR n = MAX('ДПБ_Календарь'[МесяцИндекс]) - mn + 1 VAR perv = CALCULATE(MIN('ДПБ_Календарь'[МесяцИндекс]);ALL('ДПБ_Календарь')) RETURN IF(mn - n >= perv;CALCULATE([DSO];FILTER(ALL('ДПБ_Календарь');'ДПБ_Календарь'[МесяцИндекс] >= mn - n && 'ДПБ_Календарь'[МесяцИндекс] <= mn - 1)))
```

**Дельта DSO** — D1
```
VAR a = [DSO] VAR b = [DSO пред период] RETURN IF(NOT ISBLANK(a) && NOT ISBLANK(b);a - b)
```

**Оборот Дт год назад** — D0
```
VAR mn = MIN('ДПБ_Календарь'[МесяцИндекс]) VAR mx = MAX('ДПБ_Календарь'[МесяцИндекс]) VAR perv = CALCULATE(MIN('ДПБ_Календарь'[МесяцИндекс]);ALL('ДПБ_Календарь')) RETURN IF(mn - 12 >= perv;CALCULATE([Оборот Дт];FILTER(ALL('ДПБ_Календарь');'ДПБ_Календарь'[МесяцИндекс] >= mn - 12 && 'ДПБ_Календарь'[МесяцИндекс] <= mx - 12)))
```

**Прирост оборота гг** — P1
```
VAR b = [Оборот Дт год назад] RETURN IF(b > 0;DIVIDE([Оборот Дт] - b;b))
```

**Дельта DSO значимая** — D1
```
IF([Доля оборота] >= MAX('ДПБ_Параметры'[Порог_доли]);[Дельта DSO])
```

**Период ПБЕ текст** — G
```
FORMAT(MIN('ДПБ_Календарь'[Дата]);"MM.yyyy") & " – " & FORMAT(MAX('ДПБ_Календарь'[Дата]);"MM.yyyy") & "  ·  " & [Месяцев ПБЕ] & " мес."
```

**Ранг ПБЕ** — W
```
IF(HASONEVALUE('ДПБ_ПБЕ'[ПБЕ]) && NOT ISBLANK([Оборот Дт]);RANKX(ALLSELECTED('ДПБ_ПБЕ'[ПБЕ]);[Оборот Дт]))
```

**Оборот Дт млн** — D1
```
DIVIDE([Оборот Дт];1000000)
```

**Средняя ДЗ млн** — D1
```
DIVIDE([Средняя ДЗ];1000000)
```

**ДЗ на конец млн** — D1
```
DIVIDE([ДЗ на конец];1000000)
```

**Авансы на конец млн** — D1
```
DIVIDE([Авансы на конец];1000000)
```

**Излишек ДЗ млн** — D1
```
DIVIDE([Излишек ДЗ];1000000)
```
